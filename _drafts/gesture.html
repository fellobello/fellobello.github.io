Webcam vision pipeline from scratch

A C++ webcam pipeline with every step, from the camera driver to the bounding boxes, written by hand. The goal is hand and gesture tracking; the pipeline works, and hand detection is next.

When
2025 – present
Stack
C++23, Linux V4L2, CMake. OpenCV is used only to put frames on screen.
Code
github.com/fellobello/gesture_capture

Why no libraries

The point was to understand what a vision library does for you. The only outside code shows the window; capture, color conversion and every image operation are my own.

How it works

Talking to the camera driver

Frames come straight from the Linux kernel's V4L2 API: open /dev/video0, negotiate a YUYV format with ioctl, request buffers, mmap them into the process, then queue and dequeue them each frame. YUYV is converted to RGB with fixed-point integer math (the standard BT.601 coefficients, scaled and shifted) instead of floating point.

The per-frame pipeline

  1. Blur. A separable box blur: one horizontal pass, one vertical, so each pixel costs 2k reads instead of k².
  2. Skin mask. Convert to HSV and keep pixels inside two hue ranges with minimum saturation and brightness.
  3. Threshold a grayscale copy into a binary mask.
  4. Group pixels. A breadth-first flood fill walks each connected blob and records its bounding box, which is drawn back onto the color frame.

Keyboard shortcuts switch between the color, grayscale and skin-mask views.

Where it's going

  1. Find hands with the skin mask (boxes currently come from a brightness mask), filtered by blob area and shape.
  2. Count raised fingers from each hand's outline with a convex hull, without needing training data.
  3. Track hands across frames and recognize simple gestures from finger count and motion.
  4. Swap the blur for a running-sum version so its cost doesn't depend on the kernel size.
