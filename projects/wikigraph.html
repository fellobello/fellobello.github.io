Wikigraph

Builds a prerequisite knowledge graph for any topic from Wikipedia, then lets you explore it in 2D or 3D with the foundations at the bottom.

Why I built it

In school I have found myself needing to do a lot of the learning independently. For some more advanced topics I often would start at wikipedia to get an understanding what to learn. I wanted a map for any topic to guide my learning, built automatically from Wikipedia instead of by hand.

What it does

  • Builder: python3 wikigraph.py build "Linear algebra" -o linalg.json crawls Wikipedia and writes a graph file.
  • Layered 2D and 3D views: each concept sits at a level based on its prerequisite knowledge.
  • Tracing: highlight a concept's prerequisites to get a learning path to it.
  • Pillars ranking: the concepts with the highest betweenness centrality, which the most other ideas route through.

Interesting parts

Keeping the crawl finite

Following every link on Wikipedia never ends. The builder follows only the links in each article's definition, the first lead paragraph outside parentheses. Those links point at more basic ideas, so the crawl narrows toward foundations instead of spreading sideways. Filters drop people, places, fields of study and lists. A best-first node budget expands the most-cited concepts first, and "bedrock" concepts such as set and equality are never expanded.

Turning a link graph into layers

Raw Wikipedia links contain cycles and many redundant edges. The builder breaks each cycle by keeping edges from the more widely cited concept, then applies transitive reduction: it drops A→C whenever A→B→C exists. Then it computes each node's level, betweenness centrality and PageRank. Offline tests run the whole pipeline against a fake Wikipedia built by Claude.
