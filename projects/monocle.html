Monocle

An early-stage service that tells people where their personal details appear online, and helps get them removed.

When
2026 – present
Status
Runs end to end locally on fake data. Not deployed.
Stack
PostgreSQL, Python, TypeScript (Fastify, Next.js), Redis, Docker Compose
Code
Private for now

The idea

Data brokers and breaches spread people's names, addresses and phone numbers around. Monocle lets you check what's out there about you, but only confirms things to you once you've proven they're yours, so the tool can't be used to look other people up.

Design rules I'm building around

  • Confirm, don't reveal. Answers get more detailed only as you prove more about who you are.
  • Deletion is real. Removing your data deletes it and adds you to a suppression list, so it can't be re-imported later.
  • Personal data is encrypted at rest, and the audit log is tamper-evident.

How it's put together

Three separate PostgreSQL databases, a Python ingest pipeline that normalizes and de-duplicates records, and an API with a background worker. Everything runs locally in Docker with stand-ins for the cloud services it would use in production.
