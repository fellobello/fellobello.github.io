Roughcut

A Claude Code plugin that turns a software idea into a working sample, a round at a time: agents plan it, build the pieces in parallel, merge and test them, then ask you a short list of questions.

Why I built it

I wanted to go from a notebook-style idea to something I could click through without writing a full spec first. Roughcut builds a rough first version, then asks me what it guessed wrong, so each round gets closer to what I actually meant.

What it does

  • Takes an idea in a sentence or two and plans it as modules with written interfaces.
  • Builds the modules in parallel, each task in its own git worktree, then merges and runs every test.
  • Stops with a short list of questions. Your answers decide what the next round builds, and changing an answer rebuilds only what depends on it.

Interesting parts

Interfaces first, tests from the spec

The planner writes the interfaces as real code before any builder starts, so modules can be built at the same time without guessing about each other. Each module's tests are written by a separate agent that never reads that module's implementation, so the tests check the spec and not the code.

One writer for shared state

Agents don't talk to each other directly. They communicate through files in a .hub/ folder that only one script writes, and it locks every change.

Example

From the one-line idea "google maps but you can see flock cameras and plan routes around them," the first round planned six modules, built them with acceptance tests in parallel and merged them into a working web app with 591 passing tests. It then handed back 11 big guesses to confirm. The result is alpr-route-planner. Agents wrote all of that code; the plan and every decision are in its .hub/ folder.

What I'd do next

Run more rounds on different ideas and see where the questions stop being useful.
