ALPR Route Planner

A map of automated license plate reader (ALPR) cameras, including Flock Safety cameras, that plans a driving route around them next to the normal fastest route.

When

Status
Sample build. Working code with placeholder visuals. Run it locally with npm start or offline with npm run offline.

Code
github.com/fellobello/alpr-route-planner

Why I built it

The starting idea was one line: a map app that shows Flock cameras and plans routes around them. I gave that to Roughcut and it built a working version.

What it does

  • Shows ALPR cameras from OpenStreetMap on a Leaflet map.
  • Click the map once for the start and again for the end. It draws the fastest route and a route that avoids the mapped cameras.
  • Runs offline with made-up sample cameras and a straight-line stub router, so it can be tried without a network.

Interesting parts

Tests that never touch the network

Outside services are faked through injected fetch, so the test suite runs without reaching OpenStreetMap or the routing server. The acceptance tests were written from the spec, not from the code.

Honest about its limits

Camera coverage comes from crowd-sourced OpenStreetMap data and is incomplete. A route that avoids every mapped camera can still pass unmapped ones, and the app says so.
